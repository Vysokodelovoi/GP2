В папке api_2gis находятся файлы с кодом, который мы писали для того, чтобы достать необходимые нам данные через API с сайта 2GIS.

api_filial.py - через этот файл нам удалось получиться информацию с 2GIS о местоположении филиалов компании

В папке api_vk находятся файлы с кодом, который мы писали для того, чтобы достать необходимые нам данные через API с сайта Вконтакте.

api_pj_vk_users.py - через этот файл нам удалось получиться информацию о пользователях сообщества Папы Джонс по Москве
api_top_like_papa.py - через этот файл нам удалось получиться информацию о самых популярных постах в сообществе Папы Джонс по Москве
api_vk_papa.py - через этот файл нам удалось получиться информацию о комментариях в сообществе Папы Джонс по Москве
dodo_msk_comments.py - через этот файл нам удалось получиться информацию о комментариях в сообществе Додо Пиццы по Москве
dodo_top100_posts.py - через этот файл нам удалось получиться информацию о самых популярных постах в сообществе Додо Пиццы по Москве

В папке data находятся файлы результата парсинга, которые мы анализировали.

papa_johns_top100_posts.csv - файл, в котором мы собрали данные о 100 самых популярных постах в Московском ВК-сообществе "Папа Джонс"
Признаки: 5 признаков, сто постов
1) 'post_id' - id поста в Вконтакте, тип - числовой (integer)
2) 'likes' - количество лайков на посте (по этому параметру мы и выбирали самые популярные посты), тип - числовой (integer)
3) 'text_preview' - текст поста, содержит пропуски (так как не во всех постах обязателен текст при наличии фото или видео материалов), тип - строковый (string)
4) 'date' - дата и время поста, тип - числовой (integer)
5) 'link' - ссылка на пост, тип - строковый (string)

pj_vk_users.csv - файл, в котором мы собрали пользователей Московского ВК-сообщества Папа Джонс
1) 'Фамилия' - фамилия пользователя, тип - строковый (string)
2) 'Имя' - имя пользователя, тип - строковый (string)
3) 'Возраст' - возраст пользователя, тип - числовой (integer)
4) 'Пол' - пол пользователя, тип - строковый (string)
5) 'Город' - город, указанный в профиле пользователя, тип - строковый (string)
Во всех признаках датасета присутствуют пропуски, так как пользователи ВК могут не указывать какие-либо данные о себе

vk_papajohns_full_comments.csv - файл, в котором мы собрали комментарии к постам в Московском ВК-сообществе "Папа Джонс"
Признаки: 5 признаков, сто постов
1) 'post_id' - id поста в Вконтакте, тип - числовой (integer)
2) 'comment_id' - id коменатри под постом в Вконтакте, тип - числовой (integer)
3) 'user_id' - id пользователя, оставившего комменатрий, тип - числовой (integer)
4) 'date' - дата и время поста, тип - числовой (integer)
5) 'text' - текст комментария, содержит пропуски (так как не во всех комментариях обязателен текст при наличии фото или видео материалов), тип - строковый (string)

В папке notebooks находятся блокноты, с помощью которых мы анализировали полученные данные
